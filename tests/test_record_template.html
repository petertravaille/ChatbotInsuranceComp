How we tested

  • 20 test questions, written in advance with the right answer worked out from the synthetic claims and policy databases: facts, advice, rephrasings, trick questions (a year or package that doesn't exist), a privacy test, and employee questions.
  • Each question asked 3 times to the live chatbot (the Python version with Claude), each time in a fresh conversation, because answers can vary between runs.
  • Automatic checks on every answer: the key numbers and facts, plus Pete's house rules (no internal claim numbers, an Eigen risico column next to Status, and a full physio table for physio questions).
  • Read by hand: every answer was also read and compared with the expected answer, to catch mistakes the automatic checks can't see.
  • Fix and test again: every problem found was fixed, and the questions were run again (3 times each) until the API credit for the demo ran out partway through.
